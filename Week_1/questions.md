
1. Library system  
   Design a blueprint for a Book. Each book should remember its title, author, and whether it is currently borrowed. Then create several book objects and think about how the library would keep track of them.

2. Bank account  
   Design a simple Account class. Each account should remember the owner’s name and the current balance. Add a method that prints a clear statement of the balance. Create two accounts and call the method on each.

3. Cinema ticket  
   Design a Ticket class. Each ticket should remember the film title and the seat number. Add a method that prints a short confirmation of the booking. Create two tickets and call the method on each.

4.  Bank transfer  
   Design an Account class that holds an owner name and a balance. Add a method `transfer_to` that takes another Account object and an amount. Subtract the amount from the caller and add it to the other account. Create two accounts and move money between them.

5. Package delivery  
   Design a Courier class that holds a name and a maximum load. Add a method `deliver_to` that takes another Courier object and a weight. Reduce the caller’s remaining capacity and increase the other courier’s current load. Create two couriers and move a package between them.

6. Warehouse restocking  
   Design an Item class that holds a name and a current stock level. Add a method that reduces stock when units are shipped, and another method that attempts to restock. A fully depleted item must refuse further restocking until it is formally reset. Create three items and simulate two shipments followed by a restock attempt.


7. Fuel tank  
   Design a Tank class that holds a label and a current fuel level. Add a method that drains fuel when the tank is used and another method that attempts to refill. A tank that has reached zero must refuse any refill until it is formally replaced. Create three tanks and run two drain operations followed by a refill attempt.
